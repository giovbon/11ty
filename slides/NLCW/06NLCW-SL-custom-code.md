As **Custom Functions** (Funções Personalizadas) do FlutterFlow *servem para processar dados e devolver um resultado*, usado geralmente para cálculos e transformação de dados. São perfeitas para tarefas onde a interface gráfica do FlutterFlow não tem blocos nativos ou quando criar essa lógica visualmente ficaria demasiado complexo.

**Separadores Superiores (Navegação):**

- *Function Code*: é o editor de código onde escreve a função.
- *Code Copilot*: ferramenta de IA integrada para gerar ou ajustar código através de comandos em texto.
- *Test Function*: aba para testar o funcionamento da função introduzindo valores de entrada e verificando o retorno antes de a aplicar na app.

Configura:
- Nome e descrição
- *Reference* (onde a função é usada)
- Tipo do valor de retorno
- É lista? Pode ser valor nulo?
- Definição dos argumentos (entrada da função) e seu tipo
